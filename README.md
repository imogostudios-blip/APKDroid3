# بيت الظلال (Bayt Al-Thilal)

لعبة رعب ثلاثية الأبعاد تعمل في المتصفح، مبنية بـ WebGL2 بدون أي مكتبات خارجية.

## هيكل المشروع

```
bayt-althilal/
├── index.html              # الصفحة الرئيسية
├── README.md
├── css/
│   └── game.css            # أنماط الواجهة
├── js/
│   └── game.js             # محرك اللعبة بالكامل
└── assets/
    └── textures/
        ├── photos/         # خامات متكررة (1:1) للأرضيات والجدران والعشب والطوب إلخ
        │   ├── wood.png
        │   ├── tile.png
        │   ├── carpet.png
        │   ├── stone.png
        │   ├── wall.png
        │   ├── ceil.png
        │   ├── furn.png
        │   ├── brick.png
        │   ├── grass.png
        │   ├── white.png
        │   └── paper.png
        └── items/          # خامات العناصر ثلاثية الأبعاد (أسلحة، أوراق، مفاتيح...)
            ├── pistol.png
            ├── sniper.png
            ├── ammo.png
            ├── note.png
            └── key.png
```

## كيفية التشغيل

1. افتح `index.html` في متصفح حديث يدعم WebGL2 (Chrome أو Safari أو Firefox).
2. يُفضّل تشغيلها عبر خادم محلي (مثل `python -m http.server` أو Live Server) لتجنب مشاكل CORS عند تحميل الخامات.
3. اختر جودة الرسوميات ثم اضغط «ابدأ».

## التحكم

- **W A S D**: مشي
- **Shift**: ركض
- **R**: تشغيل/إيقاف المصباح
- **F**: تفاعل / التقاط / اختباء
- **E**: فتح الحقيبة
- **1 / 2**: تجهيز المسدس أو القنّاصة
- **كليك يسار**: إطلاق
- **كليك يمين**: تصويب
- **الفأرة**: نظر
- **Esc**: إيقاف مؤقت

## استبدال الخامات

يمكنك استبدال أي صورة في مجلد `assets/textures/photos/` أو `assets/textures/items/` بصورة خاصة بك بنفس الاسم.  
الخامات في `photos` يجب أن تكون مربعة (1:1) ومتكررة بسلاسة لتعمل بشكل صحيح على الأسطح.

## ملاحظات

- اللعبة تستخدم توليد صوتي إجرائي (Web Audio API).
- لا توجد مكتبات خارجية، كل شيء مكتوب بـ JavaScript خام.
- اللعبة مصممة للعب في غرفة مظلمة مع سماعات.

## فيديو المقدمة

قبل شاشة التحميل والقائمة، يتم تشغيل فيديو من المسار:

```
assets/loading/video/intro.mp4
```

- يظهر الفيديو في وضع ملء الشاشة تلقائياً.
- لا تظهر أي أزرار تحكم (إيقاف، تقدم، سرعة...) حتى لو ضغطت على الشاشة.
- يستمر لمدة دقيقة و20 ثانية (80 ثانية) ثم تختفي وتظهر شاشة التحميل.
- يمكنك استبدال ملف `intro.mp4` بأي فيديو آخر بنفس الاسم.
