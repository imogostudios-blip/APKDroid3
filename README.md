# APKDroid

مشروع ويب (ليس مشروع Android Studio) — نفس الكود الأصلي بدون أي تعديل، فقط مقسّم لملفات منظمة بحيث يتعرف عليه المتصفح (Chrome) كتطبيق ويب حقيقي قابل للتثبيت (PWA).

## هيكل المشروع
```
APKDroid_Store/
├── index.html          ← نقطة الدخول (يربط كل الملفات ببعضها)
├── manifest.json        ← اسم التطبيق + الأيقونة (لتثبيته من Chrome)
├── sw.js                 ← Service Worker بسيط (شرط أساسي لكي يعتبره Chrome تطبيق قابل للتثبيت)
├── favicon.png
├── res/
│   ├── css/
│   │   └── styles.css   ← كل الـ CSS الأصلي (منسوخ حرفياً من الملف الأصلي)
│   └── icons/
│       ├── icon-48.png … icon-512.png   ← أحجام الأيقونة المطلوبة لمعايير PWA
│       ├── icon-512-maskable.png
│       └── icon-source.png              ← الأيقونة الأصلية المرفقة
└── src/
    └── app.jsx           ← كل كود React/JSX الأصلي (منسوخ حرفياً، بدون أي تغيير في المنطق)
```

## ملاحظات
- الكود نفسه (CSS و JS/JSX) **لم يُعدَّل إطلاقاً** — فقط تم فصله عن ملف HTML الواحد إلى ملفاته الخاصة.
- `index.html` الجديد يحمّل React / ReactDOM / Babel من نفس روابط CDN الأصلية، ثم يحمّل `src/app.jsx` كملف خارجي.
- بفضل `manifest.json` + `sw.js` سيظهر خيار "تثبيت" (Install) في شريط عنوان Chrome، وسيظهر اسم التطبيق APKDroid وأيقونته المرفقة عند التثبيت على الجهاز.
- لتشغيله محلياً يجب تقديمه عبر سيرفر HTTP (وليس فتح الملف مباشرة بـ `file://`)، لأن المتصفح لا يسمح بتحميل `fetch`/`manifest`/`service worker` من `file://`. مثال بسيط:
  ```
  npx serve .
  ```
  أو أي استضافة ثابتة (Netlify, Vercel, GitHub Pages...).
